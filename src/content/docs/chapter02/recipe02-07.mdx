---
title: レシピ2-7 クォーティング
---

bash では、メタ文字と呼ばれる特別な意味を持つ記号が使用される。
そのような記号の特別な意味を失わさせ普通の文字として使用したい場合、クォーティング記法を使用する。

## `バックスラッシュ（\)`

メタ文字の前に `バックスラッシュ（\)` を置くことでメタ文字の意味を失わせることができる。
このようなメタ文字の意味を失わせること書き方のことをエスケープという。

```bash
» echo $HOME    # パラメータを表示する
/home/xxx
» echo \$HOME   # $をエスケープし、文字として取り扱う
$HOME
» echo \\       # \をエスケープし、文字として取り扱う
\
```

## `シングルクォート('')`

`シングルクォート('')` は、囲った文字列内のメタ文字を全てエスケープし、通常の文字列として取り扱うことができる。

```bash
» echo '\${HOME}:${HOME} \\\'
\${HOME}:${HOME} \\\
```

## `ダブルクォート（"")`

`ダブルクォート（"")` は、 `シングルクォート('')` に似ているがパラメータ展開とコマンド置換は行う。
`ダブルクォート（"")` 内では、必要に応じてメタ文字をエスケープする必要がある。

```bash
» echo "\"\${HOME}:${HOME} \\\""
"${HOME}:/home/xxx \"
```
