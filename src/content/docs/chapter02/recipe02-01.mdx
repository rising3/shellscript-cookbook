bash では、特に宣言せずに変数を使用できるが、明示的に変数を宣言しない場合は型は文字列となる。
明示的に変数を宣言するには、 `declare` を使用する。
例えば、整数型の変数は、`declare -i 変数名`と宣言する。

整数型の変数は、代入時の右辺の値は整数や数式として識別され代入される。

## 算術式評価

整数型の変数は、代入文の右辺が計算式として計算される。
この代入文の右辺の計算式の規則のことを算術式評価と呼ぶ。

```bash
declare -i num=1+2/3
```

整数型変数の代入以外にも `(( ))`という記法で算出式評価が使用できる。
次の例では、変数sに右辺の算出式評価の結果が代入される。

```bash
((a=1+2/3)) 
```
:::note[(( ))内の代入文の左辺の変数は何型？]
`(( ))`内の代入文の左辺の変数は、未宣言の場合は文字列型の変数となる。


```bash
((a=1+2/3)) 
echo $a # 1

a+=3
echo $a # 13
```

左辺の変数を整数型変数として取り扱うには、`declare` で整数型変数として明示的に宣言する必要がある。

```bash
declare -i a
((a=1+2/3)) 
echo $a # 1

a+=3
echo $a # 4
```
:::

算術式評価で使用できる演算子は次の通りである。

### 算術式評価の演算子

演算子 | 説明
:---: | :---
変数++ | 変数の値を評価した後で変数に1を足す
変数-- | 変数の値を評価した後で変数から1を引く
++変数 | 変数に1を足した後で変数の値を評価する
--変数 | 変数から1を引いた後で変数の値を評価する
\+     | 単項のプラス符号
\-     | 単項のマイナス符号
\~     | ビット単位の否定
\*\*   | 冪乗
\+     | 加算
\-     | 減算
\*     | 乗算
\/     | 除算 
\%     | 剰余
\<\<   | 左ビッドシフト
\>\>   | 右ビッドシフト
\&     | ビット単位のAND
\|     | ビット単位のOR
\^     | ビット単位の排他的OR
式1?式2:式3 | 式1が真であるなら式2、偽であるなら式3を評価する
式1,式2 | 式1と式2を順に評価する

### 算術式評価の代入演算子

演算子 | 説明
:---: | :---
= | 代入する
\+= | 加算した結果を代入する
\-= | 減算した結果を代入する
\*= | 乗算した結果を代入する
\/= | 徐算した結果を代入する
\<\<= | 左ビッドシフトした結果を代入する
\>\>= | 右ビッドシフトした結果を代入する
\&=   | ビット単位のANDの結果を代入する
\|=   | ビット単位のORの結果を代入する
\^=   | ビット単位の排他的ORの結果を代入する

### 算術式評価の論理演算子

演算子 | 説明
:---: | :---
\<=    | 以下
\>=    | 以上
\<     | より小さい
\>     | より大きい
==     | 等しい
!=     | 等しくない
\&\&   | 論理的AND
\|\|   | 論理的OR
!      | 論理的否定
