---
title: レシピ3-5 コマンド置換
---

コマンドの実行結果を文字列に展開する。
コマンド置換は `$(コマンド)` もしくは　`` `コマンド` ``(バックォートで囲む) と書くことでコマンドの実行し、標準出力の結果を文字列に展開する。

使用例:
```bash
» uname -o                  # unameコマンドの実行
GNU/Linux

» echo "OS: $(uname -o)"    # コマンド置換
OS: GNU/Linux

» echo "OS: `uname -o`"     # バッククオート記法
OS: GNU/Linux
```
