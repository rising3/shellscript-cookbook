---
title: レシピ3-8 プロセス置換
---

プロセスの実行結果を一時的なファイルに置換する。
プロセス置換は、入力ファイルの置換 ` <(コマンド)` と出力ファイルの置換 ` >(コマンド)` の記法が用意されている。
プロセス置換を使用すれば、「コマンドの結果を一時的なファイルに保存し、一時ファイルを処理後、削除する」といった処理を簡単に実現できる。

## 入力ファイルの置換 ` <(コマンド)`

cat コマンドは複数のファイルを引数として渡すことができ、渡されたファイルの内容を結合して標準出力に出力する。

```
使用法: cat [オプション]... [ファイル]...
```

以下の例は、work1～3のディレクトリの内容をcatコマンドで結合している。

使用例：
```bash
» cat <(ls -l work1) <(ls -l work2) <(ls -l work3) 
```

## 出力ファイルの置換 ` >(コマンド)`

tee コマンドは、標準入力をファイルにコピーし、標準出力にも出力する。

```
使用法: tee [オプション]... [ファイル]...
```

以下の例は、1～10の連番を標準出力に出力しつつ、teeコマンドが作成したファイルをgzipコマンドで圧縮している。

使用例：
```bash
» seq 10 | tee >(gzip -c > seq.gz)
```

:::tip[出力ファイルの置換は、リダイレクトやパイプで代替できる]
出力ファイルの置換は\>(コマンド) は、リダイレクトやパイプで代替できることが多い。
:::
